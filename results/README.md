# Historical experiment artifacts

Files in this directory are preserved historical outputs, not reproduced benchmarks or security validation from the portfolio repair.

The comparative benchmark script times local CA routines but supplies hardcoded TFHE values. The compared operations, security assumptions, parameters and hardware are not matched. Earlier speedup and storage ratios must not be treated as verified comparisons.

The security script runs selected statistical and key-search experiments. Those results do not establish cryptographic security, quantum resistance, NIST certification or general fully homomorphic encryption. Browser performance/resource charts are fixed illustrations and are not generated from these reports.

The current README records the actual bounded native/reference/browser checks and remaining limitations. Reproduce and independently review an experiment before using any historical number in a portfolio or publication.
